# Implémentation des Nuées dynamiques

## Description

Ce projet consiste à implémenter l'algorithme des Nuées dynamiques
pour la classification non supervisée des données.

L'objectif est de proposer une implémentation indépendante des
bibliothèques de Machine Learning, en utilisant uniquement NumPy.

## Fonctionnalités

- Importation des données CSV
- Détection des variables numériques
- Choix du nombre de classes
- Choix du type de représentation :
  - Point (cas particulier K-means)
  - Points représentatifs
  - Axes factoriels
  - Distribution probabiliste
  - Structure représentative

## Technologies

- Python
- NumPy
- CSV

## Exécution

Installer les dépendances :

pip install -r requirements.txt

Puis lancer :

python nuees_dynamiques.py
